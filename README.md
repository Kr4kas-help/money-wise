# Из долгов — к мечте

Сайт-помощник по деньгам: человек отвечает на вопросы о доходе, семье, долгах и желаниях, а система считает индивидуальный план распределения денег в рублях и процентах, подбирает модель накопления и разбирает, какие желания лишние.

Продакшен: https://money-wise-tau.vercel.app

## Стек

Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS. Данные пользователя хранятся только в браузере.

## Запуск

```
npm install
npm run dev
npm run build
```

Подробное описание структуры и правил проекта: [финанс.md](./финанс.md).

## Демо-режим

В `lib/config.ts` константа `FRESH_START`. При `true` каждый заход начинается как первый и данные не сохраняются. При `false` данные хранятся в браузере между заходами.
